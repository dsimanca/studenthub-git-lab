# Contributing to StudentHub

## Ramas (Branches)
- Siempre crea una rama nueva para trabajar. Nunca modifiques `main` directamente.
- Usa prefijos claros: `feat/`, `docs/`, `fix/`.

## Commits
- Usa mensajes descriptivos con prefijos (ej. `feat: add login`, `docs: update readme`).
- Evita mensajes como "update" o "fix" a secas.
